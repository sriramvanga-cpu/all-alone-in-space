# Admin mode

Admin mode is for testing. It lets staff and developers reach any part of the game quickly, and nothing from an admin run ever reaches the leaderboard.

## Starting an admin run

On the registration screen, enter **`admin`** as both the name and the phone number (capital letters are fine).

An admin run differs from a normal run in these ways:

- **Fuel, power and credits are topped up** to 9999 after every change, and the top bar shows them as ∞.
- **The clock gets a full day** and shows ∞. Landing odds still follow the time actually flown.
- **The top bar says "Cheat mode"** next to the name, and "Points if you land" shows a dash.
- **The score is never sent.** The end screen says "Cheat run: not sent to the board."

**Next pilot** on the end screen, or a reload, ends the admin run.

## The admin panel

The gold **Admin** button in the bottom-left corner opens the panel. Every switch acts at once, and the game keeps running underneath. **Close** or Escape shuts the panel.

### Fuel, power and credits

- **Endless: on / off** switches the top-up. While it's off, the top bar shows the real numbers.
- **Fuel, Power, Credits** and **Set** give exact amounts and switch endless off.

Too little fuel to leave ends the run as **stranded**, just as it would for a player. Setting fuel to 3 at the station does that at once, because every lane from the station costs at least 5.

### Landing

- **Normal odds:** landings settle by the chance on the landing screen.
- **Always habitable:** every landing site is habitable.
- **Always toxic:** every landing site is toxic, including the scanner's second site.

While a landing is forced, the landing screen says so.

### Clock

- **∞, 15:00, 5:00, 1:00, 0:10** set the time left. With a set clock, the top bar shows real time, the clock turns urgent under 2 minutes, and running out ends the run, as for a player. ∞ goes back to the day-long clock (and starts the time flown again from zero).
- **+1 min flown, +5 min flown** take time off the clock and add it to the time flown, which raises the landing odds.

The panel shows the landing chance the time flown gives right now.

### Map

**Jump anywhere: on / off.** While it's on:

- The star map shows every system, scanned or not. Tapping any of them puts you in its system at once, for free.
- In a system, tapping any open planet puts you there at once, for free, and arrives as a flight would: a fuel minute at a fuel stop, a topic pick at a possible home.

Fuel and power pills are hidden while jumping. Closed planets stay closed.

### Questions

**Show answers: on / off** marks the right choice with a gold border and an "Answer" tag. This works on landing questions and on the four fuel games that use choice cards: Colour clash, Fullest tank, Flight path and Element check.

### Next flight event

Pick one of the five flight events, or **By chance** for the normal random events. The one you pick happens on your next lane flight, even the first, and then the setting goes back to By chance. Jumps don't trigger it, so switch **Jump anywhere** off first.

### Replay

- **Intro film** and **How to play** play over the run, which keeps going underneath, and return to it afterwards.
- **First-time tips** brings every tip back. Each one shows again the next time its part of the game appears, starting with the current screen.

## At fuel stops

Every fuel stop in an admin run opens with a **fuel game picker** above the game:

- **Pick any of the seven games** to start a fresh minute of it. Picking the game that's already playing restarts it.
- **Leave fuel stop** goes straight back to the system map, skipping the rest of the minute and the shop.

## After a habitable landing

A normal run ends the moment a landing settles. An admin run keeps the habitable readings on screen and offers a choice:

- **Settle here** ends the run with the win and its end screen.
- **Keep flying** goes back to the map with the run still going. That planet is closed, as after any landing.

## Recipes

| To test… | Do this |
|---|---|
| A particular fuel game | Jump anywhere on, jump to a system and then to a planet with a drop, and pick the game. |
| The shop with real credits | Set exact amounts (for example 30 credits), go to a fuel stop, and let the minute run out or play it to the end. |
| A win | Landing: Always habitable. Jump to a possible home, answer, land, then **Settle here**. |
| A failed landing and its −30 s | Landing: Always toxic. Jump to a possible home, answer and land. |
| The landing odds climbing | Press +5 min flown a few times, and watch the chance on the panel, then on the landing screen. |
| The urgent clock | Clock: 1:00. |
| Losing on time | Clock: 0:10, and wait. |
| Being stranded | Fuel: 0 at the station. |
| Out-of-reach planets | Power: 1 inside a system, then tap a planet to see the shortfall note. |
| A flight event | Jump anywhere off. Pick the event, scan from where you are, then fly a lane. |
| The tips and their clips | Replay: First-time tips. |
| The opening | Replay: Intro film, then How to play. |
